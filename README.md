A simple weather application built using HTML, CSS, and JavaScript with OpenWeather API integration.

## Features
- Search weather by city
- Current weather display
- Hourly forecast
- 5-day forecast grouping
- Weather icons

## Technologies Used
- HTML
- CSS
- JavaScript
- OpenWeather API

## How It Works
The app fetches real-time weather data using OpenWeather API and dynamically updates the UI based on user input.
